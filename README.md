## 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 진입점 · Tailwind 설정 · 글로벌 스타일 |
| `app.jsx` | React 루트 컴포넌트 |
| `sections.jsx` | 모든 페이지 섹션 (Header ~ Footer) |
| `data.jsx` | 제품·회사·FAQ 등 데이터 |
| `icons.jsx` | SVG 아이콘 컴포넌트 |
| `blueprints.jsx` | 장비 도면 SVG |

## 기술 스택

- React 18 (CDN)
- Tailwind CSS (CDN)
- Pretendard + Montserrat 폰트
- GitHub Pages 정적 호스팅
